**اجعل وكلاء البرمجة يثبتون أنهم أنهوا العمل.**

`mjloop` إضافة لـ Claude Code تحوّل عمل الوكلاء إلى دورات محدودة ومدعومة بالأدلة.
يختار القائد الوكلاء المناسبين للمهمة، ويشغّلهم في سياقات معزولة، ولا يقبل النجاح إلا
بعد أن يسجّل المحرّك نتيجة أوامر التحقق الحقيقية الخاصة بمشروعك.

`الطلب ← المسار ← وكلاء معزولون ← تحقق المحرّك ← نتيجة مثبتة بالدليل`

> [!IMPORTANT]
> يدعم `mjloop` حاليًا Claude Code. محوّلات وكلاء البرمجة الآخرين ليست ضمن الإصدار
> المنشور حتى الآن.

## لماذا mjloop؟

- **الدليل بدل الثقة** — لا يستطيع ادعاء النجاح تجاوز إيصال فاشل أو مفقود من المحرّك.
- **حالة لا يستطيع الوكلاء إعادة كتابتها** — يملك خادم MCP حالة التشغيل والملفات المشتقة.
- **استقلالية محدودة** — توقف حواجز الدورات والركود والخطأ المتكرر العمل الذي لا يتقدم.
- **مسار مناسب لكل مهمة** — تعديل قصير، أو بناء متعدد الدورات، أو إصلاح يبدأ بإعادة
  الإنتاج، أو تخطيط خاضع للمراجعة.

## البدء السريع

تحتاج إلى Claude Code وNode.js 20 أو أحدث وGit.

```bash
git clone https://github.com/MohdAljahdali/mjloop.git
cd mjloop/engine
npm install
npm run build
cd ..
claude plugin marketplace add "$PWD"
claude plugin install mjloop@mjloop
```

بعد ذلك افتح Claude Code داخل مشروع ونفّذ:

```text
/mjloop:init
/mjloop:edit أضف التحقق من مدخلات نموذج التسجيل
```

> [!NOTE]
> يجب بناء النسخة الجديدة مرة واحدة لأن خادم MCP وأداة الخطافات يعملان من
> `engine/dist/`. راجع [دليل التثبيت الكامل](docs/install.ar.md) للتحقق والتحديث وحل
> المشكلات.

## اختر المسار المناسب

| الأمر | مناسب لـ | القاعدة المضمّنة |
|---|---|---|
| `/mjloop:edit <الطلب>` | التغييرات الصغيرة المحددة | دورة واحدة، ويُصعّد العمل إذا اتسع النطاق |
| `/mjloop:build <الهدف>` | الميزات والتنفيذ الأكبر | دورات متحققة متكررة حتى الاكتمال أو التوقف |
| `/mjloop:fix <المشكلة>` | الأعطال والتراجعات | إعادة إنتاج العطل قبل قبول الإصلاح |
| `/mjloop:plan <الفكرة>` | تحويل الفكرة إلى قصص قابلة للبناء | فحص الملاءمة والموافقة قبل إنشاء القصص |

استخدم `/mjloop:status` لعرض التشغيل الحالي، و`/mjloop:resume` لمتابعة تشغيل متوقف،
و`/mjloop:stop` لإنهائه، و`/mjloop:web` لفتح لوحة التحكم في المتصفح.

## ماذا يحدث في الدورة؟

1. يركّب القائد طاقمًا من المسار المختار ويسجّل سبب ضم كل مختص اختياري أو استبعاده.
2. يعمل الوكلاء المقيّدون بعقود في سياقات معزولة ومسؤوليات محددة.
3. يشغّل المحرّك أوامر التحقق المثبتة عند بداية التشغيل ويحفظ السجل الكامل خارج رواية الوكيل.
4. تصبح نتيجة التحقق الفاشلة مدخلًا للدورة التالية، ويمكن لإيصال ناجح إغلاق التشغيل.
5. توقف حواجز الأمان الدورات عند بلوغ الحد أو الركود أو تكرار الخطأ نفسه.

## أكثر من مجرد حلقة تنفيذ

- **استكشاف الميزة** — تجري مهارة `mjloop-feature-discovery` مقابلة بقرار واحد كل مرة
  وتتوقف عند موجز يمكن لشخص مراجعته والموافقة عليه.
- **توجيه واعٍ بالمشروع** — خرائط المكونات والمهارات المقبولة توجه الأدوار دون تغيير
  تشغيل جارٍ.
- **لوحة تحكم في المتصفح** — افحص التشغيل والخطط والقصص والأدلة والإعدادات والذاكرة عبر
  `/mjloop:web`.
- **مسارات قابلة للتوسعة** — أضف وكيلًا أو مهارة أو مسارًا باستخدام `/mjloop:add`.

> [!TIP]
> ابدأ بـ `/mjloop:edit` على تغيير حقيقي ومحدود؛ فهو أسرع طريقة لرؤية عقد التحقق دون
> تكلفة تشغيل متعدد الدورات.
