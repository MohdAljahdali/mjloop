**कोडिंग एजेंटों से साबित करवाएँ कि उन्होंने काम पूरा किया है।**

`mjloop` एक Claude Code प्लगइन है जो एजेंट के काम को सीमित और प्रमाण-समर्थित साइकल में
बदलता है। लीडर काम के लिए सही एजेंट चुनता है, उन्हें अलग संदर्भों में चलाता है, और सफलता
तभी स्वीकार करता है जब इंजन आपके प्रोजेक्ट के अपने सत्यापन कमांड का परिणाम दर्ज कर लेता है।

`अनुरोध → ट्रैक → अलग एजेंट → इंजन सत्यापन → प्रमाणित परिणाम`

> [!IMPORTANT]
> `mjloop` अभी Claude Code का समर्थन करता है। दूसरे कोडिंग एजेंटों के अडैप्टर अभी जारी
> प्लगइन का हिस्सा नहीं हैं।

## mjloop क्यों?

- **भरोसे के बजाय प्रमाण** — सफलता का दावा असफल या गुम इंजन रसीद को नहीं बदल सकता।
- **ऐसी स्थिति जिसे एजेंट दोबारा नहीं लिख सकते** — MCP सर्वर रन की स्थिति और व्युत्पन्न
  मैनिफेस्ट का स्वामी है।
- **सीमित स्वायत्तता** — साइकल सीमा, ठहराव और दोहराई गई त्रुटि के गार्ड बिना प्रगति वाले काम को रोकते हैं।
- **हर काम के लिए सही प्रवाह** — छोटा संपादन, बहु-साइकल बिल्ड, पहले पुनरुत्पादन वाला सुधार या समीक्षा-आधारित योजना।

## तुरंत शुरू करें

आपको Claude Code, Node.js 20 या नया संस्करण, और Git चाहिए।

```bash
git clone https://github.com/MohdAljahdali/mjloop.git
cd mjloop/engine
npm install
npm run build
cd ..
claude plugin marketplace add "$PWD"
claude plugin install mjloop@mjloop
```

फिर किसी प्रोजेक्ट में Claude Code खोलें और चलाएँ:

```text
/mjloop:init
/mjloop:edit साइनअप फ़ॉर्म में इनपुट सत्यापन जोड़ें
```

> [!NOTE]
> नए क्लोन को एक बार बिल्ड करना आवश्यक है क्योंकि MCP सर्वर और हुक CLI `engine/dist/`
> से चलते हैं। [पूरा इंस्टॉलेशन गाइड](docs/install.md) देखें।

## सही ट्रैक चुनें

| कमांड | किसके लिए बेहतर | अंतर्निहित नियम |
|---|---|---|
| `/mjloop:edit <अनुरोध>` | छोटे और केंद्रित बदलाव | एक साइकल; दायरा बढ़े तो एस्केलेट करें |
| `/mjloop:build <लक्ष्य>` | फीचर और बड़े इम्प्लीमेंटेशन | पूरा होने या रुकने तक सत्यापित साइकल दोहराएँ |
| `/mjloop:fix <समस्या>` | दोष और रिग्रेशन | सुधार स्वीकार करने से पहले विफलता पुनरुत्पादित करें |
| `/mjloop:plan <विचार>` | विचार को बनाने योग्य स्टोरी में बदलना | स्टोरी बनाने से पहले फिट जाँच और स्वीकृति |

मौजूदा रन देखने के लिए `/mjloop:status`, जारी रखने के लिए `/mjloop:resume`, रोकने के लिए
`/mjloop:stop`, और ब्राउज़र कॉकपिट खोलने के लिए `/mjloop:web` का उपयोग करें।

## एक साइकल में क्या होता है?

1. लीडर चुने हुए ट्रैक से टीम बनाता है और हर वैकल्पिक विशेषज्ञ को शामिल या अलग करने का कारण दर्ज करता है।
2. अनुबंध से बँधे एजेंट स्पष्ट जिम्मेदारियों के साथ अलग संदर्भों में काम करते हैं।
3. इंजन रन शुरू होने पर तय कमांड चलाता है और पूरा लॉग एजेंट की कहानी से बाहर रखता है।
4. असफल सत्यापन अगले साइकल का इनपुट बनता है; सफल रसीद रन बंद कर सकती है।
5. सीमा, ठहराव या एक जैसी विफलता दोहरने पर सुरक्षा गार्ड साइकल रोकते हैं।

## केवल निष्पादन से अधिक

- **फीचर खोज** — `mjloop-feature-discovery` स्किल एक बार में एक निर्णय पूछती है और ऐसे
  ब्रीफ पर रुकती है जिसे कोई व्यक्ति स्वीकृत कर सके।
- **प्रोजेक्ट-सचेत रूटिंग** — स्वीकृत कंपोनेंट मैप और स्किल चल रहे रन को बदले बिना तय भूमिकाओं का मार्गदर्शन करते हैं।
- **ब्राउज़र कॉकपिट** — `/mjloop:web` से रन, प्लान, स्टोरी, प्रमाण, कॉन्फ़िगरेशन और मेमोरी देखें।
- **विस्तार योग्य ट्रैक** — `/mjloop:add` से एजेंट, स्किल या ट्रैक जोड़ें।

> [!TIP]
> किसी वास्तविक और सीमित बदलाव पर `/mjloop:edit` से शुरू करें। बहु-साइकल लागत के बिना
> सत्यापन अनुबंध देखने का यह सबसे तेज़ तरीका है।
